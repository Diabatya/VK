# Локальный выпуск релизов

GitHub — хранилище исходников. Сборка и релизные пакеты готовятся **локально**,
без GitHub Actions и без GitHub Releases (Actions отключён на push/PR, оставлен
ручной запуск `workflow_dispatch` — только для проверки кода).

## Быстрый старт

```bash
cd /Users/denis/Devin/relise/VK/repository
export VK_KEYSTORE_PASS='<пароль keystore>'
./tools/local-release.sh
```

Скрипт сам прочитает `versionName`/`versionCode` из `app/build.gradle`,
прогонит `testDebugUnitTest`, `lintDebug`, `assembleRelease`, подпишет APK
существующим ключом приложения и соберёт комплект в
`/Users/denis/Devin/relise/VK/<versionName>/`.

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `VK_RELEASE_ROOT` | корень хранилища версий | `/Users/denis/Devin/relise/VK` |
| `VK_KEYSTORE` | путь к keystore | `~/.android/debug.keystore` |
| `VK_KEYSTORE_PASS` | пароль keystore | **обязательно** (только env) |
| `VK_KEY_PASS` | пароль ключа | = `VK_KEYSTORE_PASS` |
| `VK_KEY_ALIAS` | алиас ключа | `androiddebugkey` |

Пароли и ключи никогда не пишутся в репозиторий, каталоги версий, ZIP или логи.

## Что делает скрипт

1. Требует **чистое рабочее дерево** и перепроверяет HEAD/чистоту **после
   сборки** — изменённые во время сборки файлы не дают ложный `SOURCE_SHA`.
2. Блокирует выпуск одной версии замком (`mkdir .locks/`) — второй процесс
   той же версии корректно отказывается; перед публикацией назначение
   перепроверяется, staging никогда не переносится внутрь существующей папки.
3. Проверяет существующий каталог версии: идентичный (тот же коммит + целые
   файлы + целый ZIP по `.sha256`) — остаётся; отличающийся/повреждённый —
   **стоп** с причиной. Для новой версии `versionCode` обязан быть больше
   известного из прошлых каталогов и тегов.
4. Собирает и тестирует локально (JDK 17, Android SDK 34 на Mac).
5. Подписывает существующим ключом (`zipalign` + `apksigner`), затем
   проверяет по сохранённому выводу инструментов: `applicationId`,
   `versionName`, `versionCode`, отсутствие `debuggable`, **точный
   сертификат** `7e3a090c…fc3c2`, схемы v2+v3 и выравнивание после подписи.
   Ошибка или пустой разбор — стоп, а не «ок».
6. Формирует комплект в staging: APK, архив исходников ревизии
   (`git archive`), LICENSE, THIRD_PARTY_NOTICES, RELEASE_NOTES
   (авто-журнал с предыдущего тега), BUILD_INFO, SHA256SUMS (внутри ZIP),
   итоговый ZIP и `caxarok_<v>_release.zip.sha256` рядом с ним.
7. Проверяет ZIP распаковкой и сверкой хешей и **атомарно** переносит
   комплект — при ошибке staging/check-каталоги удаляются полностью.

## Структура

```
/Users/denis/Devin/relise/VK/
  repository/            клон исходников (GitHub = источник правды)
  4.3.1/                 сохранённый опубликованный релиз
  <versionName>/         локально собранные версии (по мере выпусков)
    caxarok_<v>.apk      подписанный release APK
    source-<v>.tar.gz    исходники точной ревизии
    SHA256SUMS           контрольные суммы файлов комплекта
    BUILD_INFO.md        версия, коммит, инструменты, подпись
    RELEASE_NOTES.md     описание изменений
    LICENSE, THIRD_PARTY_NOTICES.md
    caxarok_<v>_release.zip         весь комплект одним файлом
    caxarok_<v>_release.zip.sha256  контрольная сумма ZIP
```

## Ограничения

- Неподписанный `assembleRelease` — не установочный APK; готовый APK только
  после подписи существующим ключом приложения (обновление поверх прежних версий).
- Новый ключ не создаётся; при недоступности ключа скрипт завершается ошибкой.
